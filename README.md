# Project-0-cs50

Project-0-cs50 is the submission record for CS50 Problem Set 0, which asks students to build a project in Scratch. The repository does not hold the Scratch project file itself. It holds `project.sb3.rtf`, a small rich text file that contains a link to the project on the Scratch website (`https://scratch.mit.edu/projects/1286335622`) and the word "Project". The Scratch project is viewed and run on scratch.mit.edu.

## Requirements

- A web browser to open the Scratch project link.
- Optionally the Scratch 3 desktop editor if you want to download the `.sb3` from the Scratch site and open it offline.

## Setup

```bash
git clone https://github.com/samarthpaliwal/Project-0-cs50.git
cd Project-0-cs50
```

## Usage

Open `project.sb3.rtf` in a text editor or TextEdit to read the link, or go directly to:

```
https://scratch.mit.edu/projects/1286335622
```

On the Scratch page, click the green flag to run the project. Controls depend on the project itself and are not documented in this repository.

## How it works

The repository is a pointer rather than source code. Scratch projects are stored on scratch.mit.edu; the `.rtf` file was exported from a text editor and contains the hyperlink to that project. Nothing in the repository executes locally.
